### Project Description
This interactive R Shiny portfolio dashboard fetches historical equity market data from Yahoo Finance via `quantmod` and visualizes price action across Daily, Weekly, and Monthly time frames using Line, Area, and Candlestick charts built with `ggplot2`. Users can dynamically toggle technical indicator layers—Simple Moving Averages (SMA), Relative Strength Index (RSI), and Moving Average Convergence Divergence (MACD)—and customize Moving Average crossover parameters to generate and annotate automated **Buy**, **Sell**, and **Hold** trading signals directly on the price chart[cite: 2, 3, 4, 5].
